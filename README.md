# 本リポジトリについて
RaiseTechのAWS課題提出用リポジトリとなります。

# 概要
各課題を通し、AWS上で各サービスを用い、クラウドにサーバーを自動構築することを最終目的として進めました。

# 提出した各課題の内容
### lecture02
GitHub リポジトリの作成、Pull Request の提出、Cloud9 の Git 設定

### lecture03
Cloud9 上にサンプルアプリケーションをデプロイ、AP サーバ・DB サーバについて調べる

### lecture04
AWS で VPC・EC2・RDS の作成、EC2 から RDS へ接続

### lecture05
EC2 上にサンプルアプリケーションをデプロイ、ALB の追加、S3 の追加、構成図の作成

### lecture06
CloudTrail から AWS 利用記録を抽出、CloudWatch アラームの設定・Amazon SNS でメール通知設定、AWS 利用料の見積もり作成

### lecture10
CloudFormation で AWS 環境をコード化

### lecture13
CircleCI に CloudFormation、Ansible、ServerSpec の処理を組み込み

### lecture14
AWS 構成図、自動化処理がわかる図、リポジトリの README 作成
